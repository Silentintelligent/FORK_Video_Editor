# FORK

A free, open-source video editor for Android (and desktop), forked from
[Concat](https://github.com/jub0t/Concat) by Jareer (@jub0t). FORK is an
independent project: it is **not** Concat, is not endorsed by or affiliated
with the Concat author, and does not use the Concat name or logo.

Everything runs on the device. Auto-captions, text-to-speech, background
removal and other AI features use models you download once from Settings.
